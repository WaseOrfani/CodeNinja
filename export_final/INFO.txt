📦 INHALT DES PAKETS
--------------------
- index.html          → React Frontend (SPA)
- static/             → CSS & JavaScript
- api/                → PHP Backend
- 001_schema.sql      → Datenbank-Schema
- 002_seed_menu.sql   → Produktdaten (31 Artikel)
- .htaccess           → Apache Routing


🚀 INSTALLATION (5 Minuten)
---------------------------

SCHRITT 1: DATENBANK ERSTELLEN
   - Loggen Sie sich in phpMyAdmin ein
   - Erstellen Sie eine neue Datenbank: "oriafresh"
   - Importieren Sie: 001_schema.sql
   - Importieren Sie: 002_seed_menu.sql

SCHRITT 2: DATENBANK KONFIGURIEREN
   - Öffnen Sie: api/config/database.php
   - Passen Sie die Zugangsdaten an:

     define('DB_HOST', 'localhost');
     define('DB_NAME', 'oriafresh');
     define('DB_USER', 'IHR_DB_BENUTZER');
     define('DB_PASS', 'IHR_DB_PASSWORT');

SCHRITT 3: DATEIEN HOCHLADEN
   - Laden Sie ALLE Dateien in Ihr public_html/ Verzeichnis
   - Achten Sie darauf, dass .htaccess mit hochgeladen wird

SCHRITT 4: TESTEN
   - Öffnen Sie: https://ihre-domain.de
   - Der Shop sollte 31 Produkte anzeigen
   - Testen Sie: https://ihre-domain.de/api/categories
     (sollte JSON mit 5 Kategorien zurückgeben)

🗂️ DATENBANK-TABELLEN
----------------------

- admins         → Admin-Benutzer
- settings       → Shop-Einstellungen
