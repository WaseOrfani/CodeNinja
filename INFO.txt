═══════════════════════════════════════════════════════════════════
                      SCHNELLSTART
═══════════════════════════════════════════════════════════════════

1. Dateien auf Server kopieren
2. cp .env.example .env
3. .env anpassen (JWT_SECRET, BACKEND_URL, CORS_ORIGINS)
4. docker compose up -d --build
5. docker compose exec backend python seed_data.py
6. Im Browser öffnen: http://ihre-server-ip

Detaillierte Anleitung: siehe INSTALL.md
