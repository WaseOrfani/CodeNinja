# ORIA FRESH – Roadmap V2
## Features nach dem Go-Live

---

## 🚀 PHASE 1: Kurzfristig (2-4 Wochen nach Start)

### 1.1 Lieferung (eigene Fahrer)
- [ ] Liefergebiet definieren (Radius/PLZ)
- [ ] Mindestbestellwert für Lieferung (z.B. €15)
- [ ] Liefergebühr (z.B. €2.50)
- [ ] Fahrer-App oder WhatsApp-Gruppe
- [ ] Lieferzeitfenster wählbar

**Aufwand:** ~2-3 Tage Entwicklung

### 1.2 Upsell-Optimierung
- [ ] Bestseller-basierte Empfehlungen
- [ ] "Andere Kunden bestellten auch"
- [ ] Bundle-Angebote (2 Burger + Pommes + 2 Drinks)
- [ ] Happy Hour Preise (zeitgesteuert)

**Aufwand:** ~1 Tag Entwicklung

### 1.3 Analytics Dashboard
- [ ] Tagesumsatz-Grafik
- [ ] Bestseller-Ranking
- [ ] Durchschnittlicher Bestellwert
- [ ] Bestellungen pro Stunde
- [ ] Conversion Rate (Besucher → Bestellung)

**Aufwand:** ~2 Tage Entwicklung

---

## 📱 PHASE 2: Mittelfristig (1-2 Monate)

### 2.1 QR-Bestellung im Restaurant
- [ ] QR-Code am Tisch
- [ ] Tischnummer-Eingabe
- [ ] "Zum Tisch servieren" Option
- [ ] Kellner-Benachrichtigung

**Aufwand:** ~3 Tage Entwicklung

### 2.2 Treuepunkte-System
- [ ] 1 € = 1 Punkt
- [ ] Stufen: Bronze (100P) / Silber (500P) / Gold (1000P)
- [ ] Prämien: Gratis-Pommes, 10% Rabatt, etc.
- [ ] Punkte-Stand im Profil
- [ ] Geburtstags-Bonus

**Aufwand:** ~4-5 Tage Entwicklung

### 2.3 Gutschein-System
- [ ] Prozent-Rabatt (z.B. 10%)
- [ ] Festbetrag (z.B. €5 ab €25)
- [ ] Gratis-Produkt
- [ ] Einmal/Mehrfach verwendbar
- [ ] Gültigkeitszeitraum

**Aufwand:** ~2 Tage Entwicklung

### 2.4 Bewertungs-System
- [ ] Nach Abholung Bewertung anfragen (E-Mail)
- [ ] 1-5 Sterne + Kommentar
- [ ] Anzeige auf Website
- [ ] Google Reviews Integration

**Aufwand:** ~2-3 Tage Entwicklung

---

## 🏢 PHASE 3: Langfristig (3-6 Monate)

### 3.1 Native App / PWA
- [ ] Push-Benachrichtigungen
- [ ] Offline-fähig
- [ ] Schnellbestellung (letzte Bestellung wiederholen)
- [ ] Apple Pay / Google Pay
- [ ] Face ID / Fingerprint Login

**Aufwand:** ~2-3 Wochen Entwicklung

### 3.2 Mehrere Standorte
- [ ] Standort-Auswahl beim Start
- [ ] Separate Öffnungszeiten pro Standort
- [ ] Zentrale Produktverwaltung
- [ ] Standort-spezifische Preise (optional)
- [ ] Franchise-Admin-Rollen

**Aufwand:** ~2 Wochen Entwicklung

### 3.3 Catering / Vorbestellung
- [ ] Großbestellungen (>10 Personen)
- [ ] Kalender-Integration
- [ ] Individuelle Anfrage-Formulare
- [ ] Angebotsstellung
- [ ] Vorauszahlung

**Aufwand:** ~1 Woche Entwicklung

### 3.4 Social Features
- [ ] "Mit Freunden teilen"
- [ ] Gruppen-Bestellung
- [ ] Instagram-Feed einbinden
- [ ] User Generated Content

**Aufwand:** ~1 Woche Entwicklung
