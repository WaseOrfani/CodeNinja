🚫 Kunde kommt nicht

  1. Sofort Kunde anrufen
  2. Alternative anbieten
  3. Falls nein → Teilstorno

🚫 Falsche Bestellung

  1. Richtige sofort neu machen
  2. Fehler im Admin notieren
  3. Team informieren
