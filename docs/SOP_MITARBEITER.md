# ORIA FRESH – Online-Bestellungen
## Standard Operating Procedure (SOP) für Mitarbeiter

---

## 📋 ABLAUF IN 4 SCHRITTEN

### 1️⃣ BESTELLUNG KOMMT REIN
- **E-Mail-Benachrichtigung** oder **Admin-Dashboard prüfen**
- Status ist: `bezahlt` oder `ausstehend`
- **Abholzeit** sofort prüfen!

### 2️⃣ ZUBEREITUNG STARTEN
- Im Admin → Bestellung öffnen
- Status ändern: **`In Zubereitung`**
- NUR das zubereiten, was im System steht
- Sonderwünsche beachten (gelb markiert)

### 3️⃣ BESTELLUNG FERTIG
- Status ändern: **`Abholbereit`**
- Bestellung beschriften (Nummer oder Name)
- An Abholplatz stellen

### 4️⃣ ÜBERGABE AN KUNDE
- Kunde nennt **Name** oder **Bestellnummer**
- Bestellung übergeben
- Status ändern: **`Abgeholt`**

---

## ⚠️ WICHTIGE REGELN

| Regel | Warum |
|-------|-------|
| Status IMMER sofort aktualisieren | Kunde sieht den Status |
| Sonderwünsche nur über den Shop | Vermeidet Fehler |
| Bei Problemen → Telefonnummer nutzen | Steht in der Bestellung |
| Keine Änderungen ohne Admin | Preise & Extras sind fix |

---

## 🚨 PROBLEMFÄLLE

### Kunde kommt nicht
- Nach 30 Min. versuchen anzurufen
- Nach 60 Min. → Status: `Storniert`
- Ware entsorgen (dokumentieren)

### Produkt nicht verfügbar
1. Sofort Kunde anrufen
2. Alternative anbieten
3. Falls nein → Teilstorno im Admin

### Falsche Bestellung zubereitet
1. Richtige Bestellung sofort neu machen
2. Fehler im Admin dokumentieren
3. Team informieren

## 📊 STATUS-ÜBERSICHT

```
BEZAHLT → IN ZUBEREITUNG → ABHOLBEREIT → ABGEHOLT
                ↓
           [STORNIERT]
```

| Status | Bedeutung | Nächste Aktion |
|--------|-----------|----------------|
| Ausstehend | Zahlung offen | Warten auf Zahlung |
| Bezahlt | Zahlung eingegangen | Zubereitung starten |
| In Zubereitung | Küche arbeitet daran | - |
| Abholbereit | Fertig zum Abholen | Warten auf Kunde |
| Abgeholt | Übergeben | Erledigt |
| Storniert | Abgebrochen | Erledigt |
